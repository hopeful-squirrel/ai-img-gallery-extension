# 갤러리 프롬프트 패널

NovelAI 이미지 생성 화면에서 [갤러리](https://gallery.ai-thanks.com)의 프롬프트를
바로 꺼내 쓰고, 새로 만든 프롬프트를 이미지와 함께 저장하는 크롬 확장입니다.

- **적용** — 패널에서 프롬프트를 누르면 NAI 프롬프트 창에 바로 들어갑니다.
- **교체** — 다른 프롬프트를 적용하면 앞서 넣은 부분만 정확히 바뀝니다.
  넣은 뒤에 직접 고쳐 쓰셔도 경계를 계속 따라갑니다.
- **드래그 저장** — NAI 프롬프트 창에서 텍스트를 드래그하면 `📁 갤러리에 저장` 칩이 뜹니다.
  누르면 드래그한 텍스트와 화면에 떠 있는 생성 이미지가 채워진 채로 저장 폼이 열립니다.

## 설치

1. 이 저장소의 [Releases](../../releases)에서 zip 파일을 받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** 를 누르고, 압축 푼 폴더를 선택합니다.
5. `novelai.net/image` 를 열고 툴바의 확장 아이콘을 누르면 패널이 열립니다.

로그인은 따로 하지 않아도 됩니다. 갤러리 관리자로 이미 로그인해 두셨다면
그 상태를 그대로 사용합니다. 로그인이 안 되어 있으면 패널에 안내가 뜹니다.

## 사용법

**프롬프트 넣기**
프롬프트 창에서 원하는 위치를 클릭해 커서를 두고, 패널에서 프롬프트를 누릅니다.
커서를 두지 않으면 설정에서 정한 기본 위치(기본값: 커서 위치, 없으면 맨 뒤)에 들어갑니다.

**바꿔 끼우기**
추적 중인 구간은 프롬프트 창에 앞뒤로 `✦` 마커가 붙습니다.

```
1girl, ✦silver hair, smile✦, outdoors, best quality
```

다른 프롬프트를 적용하면 `✦` 사이만 바뀌고 앞뒤는 그대로 남습니다.
계속 유지하고 싶은 프롬프트는 `✦` 바깥에 적어 두세요.
마커 표시를 끄거나 글자·배경 색을 바꾸는 것은 설정(⚙)에서 할 수 있습니다.

패널 상단 배너에서 지금 적용 중인 프롬프트와 수정 여부를 볼 수 있고,
`추적 해제`(텍스트는 그대로 두고 연결만 끊기)와 `텍스트 삭제`도 가능합니다.

**새 프롬프트 저장**
NAI에서 텍스트를 드래그 → `📁 갤러리에 저장` 칩 클릭 → 제목을 적고 저장합니다.
저장 위치는 폴더를 눌러 들어가는 방식이며, 지금 들어가 있는 폴더가 저장 위치가 됩니다.
`＋ 하위 폴더`로 현재 위치에 폴더를 만들어 바로 저장할 수도 있습니다.

추가 프롬프트는 3개까지 함께 저장됩니다. 메인 칸이 차 있는 상태에서 다시 드래그하면
빈 추가 칸에 자동으로 들어갑니다.

이미지가 자동으로 잡히지 않으면 `NAI 이미지 가져오기`를 다시 누르거나
`파일 선택`으로 직접 첨부하세요.

**메타데이터(EXIF)**
갤러리 설정에서 PNG 원본 보존을 켜두었다면 안내가 표시됩니다.
꺼져 있어도 저장 폼의 `원본 그대로 저장` 체크로 이 글만 원본으로 남길 수 있습니다.

## 알려진 한계

- 크롬에서, `novelai.net` 에서만 동작합니다.
- 넣고 빼는 대상은 Base Prompt 입력창 하나입니다.
  UC·캐릭터 프롬프트 창에서는 드래그 저장만 지원합니다.
- 이미지 자동 가져오기는 생성 결과가 화면에 크게 표시 중일 때 동작합니다.
- NovelAI가 화면 구조를 바꾸면 일시적으로 동작하지 않을 수 있습니다.
